# Simulation contract v1

Grid cells are one metre square. Robot positions are cell centres; four-neighbor actions move one cell linearly in one tick or stay still. Static obstacles occupy entire blocked squares. Robots are discs with a configurable radius from 0.1 to 0.45 m. Tangency within 1e-9 m is treated as a collision. There is no acceleration, localization error, noisy sensor, physical robot, or network delay model.

Input: a rectangular array of strings using `.` for free and `#` for blocked cells; 3–40 columns and rows, at most 1600 cells. Options: `policy` (`random`, `frontier`, `gossip`), integer seed 0–4294967295, robots 1–16, ticks 1–1000, sensor radius 1–8 cells, communication radius 0–20 m, disc radius 0.1–0.45 m, target visited coverage 0.1–1, dt 0.1–10 seconds. Reject work above 10 million robot×cell×tick units or 80 million robot²×cell×tick units. Replay output is bounded to 1001 frames, 16016 robot-position records and 2 MiB serialized JSON. Optional starts are unique valid free cell centres with non-overlapping discs; otherwise deterministic starts are selected around a seeded free-cell anchor. All configuration is validated before running.

Each agent starts with an empty private occupancy/visited map and scans with perfect grid-ray sensing. Rays stop at the first obstacle. At each tick, `gossip` exchanges a previous-step snapshot only with robots within range and grid line of sight. Each robot independently runs known-map BFS to a frontier or an unvisited known free cell; local peer target penalties use previous targets. Goals persist until reached, depleted, reserved by a lower-ID neighbor, or temporarily unreachable. Both frontier policies observe nearby robot positions, avoid them in the known-map BFS, and use the same seeded local escape after three no-motion ticks. `frontier` uses the same policy without map/visited sharing or peer target penalty. `random` chooses a known free cardinal neighbor or waits, using a seeded PRNG. No policy sees the simulator's ground-truth map directly.

The centralized simulator validates obstacle clearance and simultaneous disc motion. It rotates priority between ticks and may hold conflicting proposals. Its ground-truth safety shield is an explicit centralized assumption. Decisions and maps are local; collision prevention is not a decentralized protocol. All accepted paths are checked again. A safety check failure aborts rather than returning an unsafe replay.

Output: schema version, effective config, world, initial positions, bounded frames with position and newly seen/visited cell deltas, and metrics. Reachable free cells are the union of cardinal-connected components containing starts. `visitedCoverage` counts physically entered reachable cell centres / reachable free centres. `mappedCoverage` counts sensed reachable free centres / the same denominator. `distanceM` sums actual accepted segment lengths. `ticks` counts transitions (frame zero is initial). `timeSeconds` equals ticks×dt. `timeToTargetSeconds` is null unless the visited target was reached. `blockedMoves` counts rejected non-stationary proposals; `collisionCount` counts accepted-motion collision failures (zero for a successful report). `stallEpisodes` counts each run of at least 20 consecutive ticks with no robot movement; it is an observed stall, not proof of deadlock. Stop at target, tick budget, or 40 consecutive no-motion ticks. Seeded results exclude wall-clock performance timing.
